  ```bash

  ```bash

#### 3. **Check for Vulnerable Technologies**

  ```bash
  whatweb http://localhost:3000
  ```

#### 4. **Check for Common Vulnerabilities**
- **SQL Injection**:
  ```bash
  curl "http://localhost:3000/search?query=1' OR '1'='1"
  ```
- **XSS (Cross-Site Scripting)**:
  Try injecting scripts like:
  ```html
  <script>alert('xss')</script>
  ```
- **CSRF (Cross-Site Request Forgery)**:
  Check for forms without `csrf_token` and test CSRF tokens.
- **Insecure Direct Object References (IDOR)**:
  Try modifying URL parameters to access unauthorized data.

#### 5. **Use a Vulnerability Scanner**
- Run **OWASP ZAP** or **Burp Suite** in proxy mode to intercept and analyze traffic:
  - Start the tool and set it as a proxy.
  - Send requests to `http://localhost:3000` and analyze responses for vulnerabilities.

#### 6. **Check for Misconfigurations**
- Look for:
  - `robots.txt` or `sitemap.xml` files that expose internal paths.
  - `/.git/` or `/.svn/` directories if the app is built with Git.
  - `/.env` files if the app stores secrets in environment variables.

#### 7. **Check for Authentication Issues**
- Try brute-forcing login pages or testing for session fixation.
- Look for unauthenticated endpoints that should be protected.

#### 8. **Check for Data Exposure**
- Look for endpoints that return sensitive data like user details, logs, or config files.
- Use tools like **sqlmap** to test for SQL injection:
  ```bash
  sqlmap -u "http://localhost:3000/search?query=1" --dbs
  ```
